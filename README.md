# Jogo da Cobrinha

Jogo Snake simples em HTML, CSS e JavaScript, executado no navegador.

## Estrutura

```text
.
├── index.html        # Página e canvas do jogo
└── src/
    ├── game.js       # Lógica da cobra, comida e controles
    └── style.css     # Estilos da interface
```

## Executar

Abra `index.html` em um navegador. A página carrega os arquivos de `src/` por caminhos relativos, sem etapa de compilação.
